Oracle of Olympus — passcode pages (must match oracle_clues_final.html PASSWORDS)

SETUP
  • Upload the whole website root to your host (index.html, oracle_clues_final.html, qr-code-pages/, printables/). PDFs live in printables/.
  • Passcode pages are inside qr-code-pages/ — each qr-XXXX.html shows one 4-digit code (big) plus a mini QR for testing.
  • Teams type the four digits on the laptop. The same pages can be opened by:
      – tapping an NFC tag programmed with the page URL
      – scanning the mini QR (or a larger QR you print pointing to the same URL)
      – reading the digits off the screen if you project it or print a screenshot

HYBRID LAYOUT (few NFC cards)
  • Outside storage: ONE NFC tag programmed with the URL you want for that step (often qr-7392.html for Clue I — adjust to match your story).
  • Other stops (Gazebo, Table tennis, Football goal, Storytelling chair): no NFC required. Print a QR on a sign, or print the four digits on a slip, or both.
  • Mr White does not need to scan a tag at every stop — the site copy matches that. He still runs the Gazebo and Football challenges and reads data aloud.
